# CalmReadApp — Mobile

This repository contains the CalmRead app sources and the Flutter mobile project at `calmreader_mobile/`.

Quick start

```bash
git clone <repo>
cd calmreadapp/calmreader_mobile
flutter pub get
flutter run
```
